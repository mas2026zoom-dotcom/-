# الصلاة — AL-SALAH by MAS

تطبيق أندرويد عربي RTL مبني باستخدام Kotlin وJetpack Compose، مع تصميم زجاجي وبشريط تنقل عائم.

## الوظائف المنفذة في فرع التطوير

- حساب مواقيت الصلاة محليًا من إحداثيات GPS أو البحث عن عنوان/مدينة وتحويله إلى إحداثيات أو إدخالها يدويًا، مع طرق مصر، رابطة العالم الإسلامي، أم القرى، كراتشي، ISNA وخيار العصر الحنفي.
- حساب اتجاه القبلة جغرافيًا وتصحيح البوصلة بالانحراف المغناطيسي ومستشعرات الجهاز.
- تنبيه الصلاة التالية عبر AlarmManager، وإعادة الجدولة بعد إعادة التشغيل وتغييرات التاريخ والمنطقة الزمنية. التنبيه الدقيق يتطلب منح صلاحية Android الخاصة به.
- أذكار الصباح والمساء وبعد الصلاة، مع حفظ الفئة والذكر والعداد.
- سبحة مستقلة بأهداف 33 و99 و100 و1000 وحفظ تلقائي.
- تقويم هجري شهري ومناسبات أساسية، مع التنبيه إلى احتمال اختلاف التاريخ يومًا بسبب الرؤية.
- أدعية قرآنية ونبوية مع مراجعها.
- حفظ الإعدادات محليًا باستخدام DataStore، وبنية MVVM عبر AppViewModel.
- أيقونة التطبيق الرسمية من تصميم المستخدم، مع توليد موارد Launcher تلقائيًا أثناء Gradle build.
- رجوع متدرج يحفظ تاريخ التنقل بين الشاشات والتبويبات.
- اختبار صوت الإشعار وفتح إعدادات قناة صوت تنبيهات الصلاة في Android.

## إعداد الاستخدام

1. امنح التطبيق إذن الموقع، أو أدخل خط العرض وخط الطول يدويًا من الإعدادات.
2. اختر طريقة الحساب المناسبة.
3. اسمح بإشعارات التطبيق، واسمح بالتنبيهات الدقيقة من إعدادات Android إن أردت أعلى دقة ممكنة.
4. عاير البوصلة بتحريك الهاتف على شكل رقم 8، وأبعده عن المغناطيس والمعادن.

## البناء والاختبارات

- Java 17
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Kotlin 2.0.21
- Android SDK 35 / minSdk 26
- اختبارات وحدات للحسابات، واختبار تشغيل وتنقل عبر Android Emulator في GitHub Actions.

الأمر المحلي:
```bash
gradle --no-daemon testDebugUnitTest assembleDebug
```

## ملاحظة إصدار

فرع `feature/full-app-implementation` هو فرع التطوير. لا تُعتبر أي نسخة APK نهائية إلا بعد نجاح جميع وظائف واختبارات أحدث commit، ونجاح رفع artifact `al-salah-debug-apk`.
